1. Registration & Login

Guest le website ma aayera Student or Tutor vanera register garxa → users table ma entry banxa (role field le differentiate garxa)


Tutor le register garda thap details (bio, qualification, experience_years, hourly_rate) pani bharnu parxa → tutor_profiles table ma janxa, status = 'pending' set hunxa

2. Admin Approval

Admin le login garera pending tutors haru herxa
Tutor ko qualification/details check garera approve or reject garxa → tutor_profiles.status update hunxa
Approved navako tutor student ko search result ma dekhindaina

3. Tutor Subject Setup

Approved tutor le aafule padhaune subjects select garxa (Math, Physics, etc.) → tutor_subjects junction table ma entries banxa

4. Student Search & Browse

Student le login garera subject, location, price ko basis ma tutor search/filter garxa
Tutor list herera profile herxa (rating, experience, rate)

5. Booking Request

Student le tutor lai booking request pathauxa (date, time, message sanga) → booking_requests table ma entry banxa, status = 'pending'
Tutor lai notification janxa → notifications table

6. Tutor Response

Tutor le request herera Accept or Reject garxa → booking_requests.status update hunxa
Student lai notification janxa (accepted/rejected)

7. Session Happens (Offline)

Accept vaye pachi tutor ra student le real life ma ya call ma coordinate garera padhne
Session complete vayepachi admin/tutor le status 'completed' ma update garxa (manually ya button click bata)

8. Review & Rating

Session complete vayepachi student le rating + comment dinxa → reviews table ma entry (booking_id sanga linked)

9. Admin Monitoring

Admin le dashboard bata total users, pending approvals, total bookings, reviews sabai monitor garxa
